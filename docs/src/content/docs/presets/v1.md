---
title: V1 Preset
---

This is Arbor's current recommended preset. It uses a minimal set of purely semantic tokens (no component-level tokens) with succinct names for repetitive typing in CSS.

The v1 preset has many customization options, from specifying colors to tweaking typography to directly overriding spacing and other scales.

V1 [inherits from Basic](./basic.md), which includes the full color system, so be sure to read up on that first or you'll miss a lot of the feature set.

## The Mode Schema

Most importantly, V1 provides a baseline mode schema - the set of tokens you'll actually apply to your CSS. V1's schema is designed for flexibility.
